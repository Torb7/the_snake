# Snake — игра «Змейка»

Классическая игра «Змейка», реализованная на Python с использованием библиотеки Pygame.

Управляйте змейкой, собирайте яблоки и увеличивайте её длину. Игра завершается автоматически при столкновении змейки с собственным телом.

## Возможности

- Управление змейкой с помощью клавиш-стрелок.
- Случайная генерация положения яблок.
- Увеличение длины змейки после сбора яблока.
- Обнаружение столкновений змейки с собственным телом.
- Перемещение через границы игрового поля.
- Возможность перезапустить игру после столкновения.
- Обработка пользовательских событий и управление игровым циклом.

## Технологии

- **Python 3** — основной язык разработки.
- **Pygame** — создание игрового окна, обработка событий, отрисовка графики и управление временем.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git https://github.com/Torb7/the_snake
cd the_snake
```

### 2. Создание виртуального окружения

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск игры

```bash
python the_snake.py
```

## Управление

| Клавиша | Действие |
|---|---|
| ↑ | Движение вверх |
| ↓ | Движение вниз |
| ← | Движение влево |
| → | Движение вправо |
| ESC | Выход из игры |

## Особенности реализации

Проект построен с использованием объектно-ориентированного подхода.

- **GameObject** — базовый класс игровых объектов, содержащий общие свойства и методы отрисовки.
- **Snake** — класс змейки, отвечающий за перемещение, изменение направления, увеличение длины и сброс состояния.
- **Apple** — класс яблока, отвечающий за случайное размещение на игровом поле с учётом занятых ячеек.

Игровая логика организована в основном цикле, который последовательно обрабатывает пользовательский ввод, обновляет состояние объектов, проверяет столкновения и выполняет отрисовку игрового поля.
